# 连接助手界面设计

模式：Operate。用户于 2026-10-22 指定改为苹果式极简客户端，突出连接与打开应用；主站只做必要同源挂载和安全登录回跳，不改其视觉。

最新视觉指令：按用户提供的《手机APP UI对标参考.png》设计。采用图中的圆润表面、彩色立体图标、柔和背景和底部中央动作；此前无阴影、单色扁平的形式不再作为限制。

## 主任务

打开连接页，识别自己的授权身份，点击连接，随后接入或启动所需 Agent。默认不要求填写 IP、端口、DNS、模型或 API Key。

## 信息结构

1. 连接：真实账号摘要、APP 宣传 Hero、常用工具与选定工具行；初始不放连接状态卡和示例 IP，操作后在 Hero 下方显示紧凑状态。底部按钮负责连接、取消、断开，工具行负责接入演示或打开方式。
2. 应用接入已并入连接首页：默认常用工具，原位展开完整分类库，唯一当前工具行下按需查看能力、指南和官方入口。不声称检测过安装或完成真实接入。旧applications链接只作兼容。
3. 出口与备用：只读主出口与专属备用；故障接管记录；无备用或套餐到期有明确恢复入口。
4. 我的：主站真实资料、账号验证、订阅状态与退出；连接偏好、外观和帮助保留分组。

## 领域与视觉

领域：授权身份、自动入口、固定出口、专属备用、故障接管、Agent 进程与本地权限。

色彩世界：近白内容底、中性浅灰侧栏、炭黑深色底、灰白文字、蓝色主动作、绿色连接状态、琥珀色需处理状态。

产品特征：一个身份连接多个工具；首页只展示完成任务所需的身份和只读出口摘要，详细路径移入出口页按需展开。

避免默认模板：巨型 VPN 电源圆环、没有来源的性能图表、API 供应商切换表。以明确动作、连接路径和可操作的应用列表替代。

## 状态边界

连接中可以取消，失败支持重试；到期阻止连接；没有备用时不能假装完成切换。原型场景控件与产品导航分开。网络与应用启动仍为演示。真实会话读取和退出复用主站接口，不通过原型场景更改真实用户身份或资源。

## 尺寸与交付

覆盖 Windows、macOS、iPhone/iPad、Android。桌面侧栏、手机底部导航、平板按可用宽度布局；375px 窄屏可用，底部避让安全区。支持键盘、可见焦点、语义状态、减少动态效果。界面与规范留在本目录，主站仅增加必要 /assistant/ 静态挂载与精确回跳。

手机不会提供本机启动 Claude Code、Codex CLI 等桌面命令行工具的按钮。移动端以已授权网络连接、官方移动应用/浏览器的使用说明为主。VPN 权限单独演示，不能声称网页已经获得系统权限或让系统其他应用走 VPN。

## 2026-10-22 精简原则

手机平台默认暗色，Windows/Mac 默认亮色，随平台切换应用各自默认主题。手动切换主题仍保留。375×812 与 1280×800 首页首屏即可找到连接按钮与目标应用。首页去掉重复说明、完整路径和多行应用按钮，信息移到应用页与出口页。失败、到期、无备用不能被简化隐藏。

视觉执行：留白充足、简短清晰标题、柔和圆角、少量中性层次；连接按钮和工具打开动作职责分开。系统级工具的熟悉操作优先，不引入大面积装饰玻璃或营销视觉。

## 用户图片的转译

- 圆形头像与简短账号信息，通知入口只呈现真实原型状态，不编造未读数。
- 应用数量较少，首页与应用库取消搜索。应用库保留类别筛选，不为参考图装饰增加无必要输入。
- 彩色渐变仅用于应用图标与主操作，图标配统一 SVG 几何描边，不使用图片中的乱码、虚构品牌或人物。
- 大圆角面板、轻柔投影、灰紫表面构成层次；手机暗色对应提高表面明度，保持可读性。
- 底部中央凸起按钮实际用于连接、取消、断开，不使用容易误解的“新增”加号。连接成功后打开所选应用是明确下一步。
- 首页仅少量常用应用快捷入口，完整库放在应用页，避免照搬图片中所有模块后淹没连接动作。

## 次级模块完善

应用库保留类别筛选，不再提供搜索、清空与搜索空态；当前工具展示入口能力，待验证与演示严格区分。

出口页优先展示只读分配、专属备用与接管历史。规则和路径折叠展开；一次接管后的断开或重连不会重置绑定，不通过重连自动回切。原型历史在身份或平台切换后清除，避免混入其他身份。

“我的”按真实账号资料、连接偏好、外观和帮助分组。账号会话读取与退出是真实主站操作；设备偏好按白名单保存到本浏览器，刷新保留，不暗示已修改系统配置。首页主要材质维持参考图版。

无需主站联调的本地能力：帮助与FAQ、已核实官方链接、本机通知与未读、脱敏诊断JSON下载/复制/手动复制降级、hash路由、按平台保存主题与应用选择、恢复默认。通知及诊断只含当前页面事件，账号变化后清除；偏好不含账号与连接凭据。开机启动和自动连接仍只是偏好，系统通知与隧道能力仍待原生层。

## 主站账号接入

同源正式查看入口固定为 /assistant/，通过 GET /api/v1/me 取得主站 HttpOnly Cookie 对应资料和内存 CSRF。未登录引导主站登录，next 只精确放行 /assistant/。退出使用 POST /api/v1/auth/logout 与 X-Requested-With: Dingtu-Portal、X-CSRF-Token。昵称、邮箱、类型、等级和验证状态以真实返回值为准；level=null 显示未订阅，不声明已分配示例出口。

4177 是独立视觉预览，不跨源鉴权；登录按钮进入主站后返回同源助手。模拟角色不得覆盖真实用户。主站仅改必要静态挂载与回跳，不另建账号模型或 localStorage 令牌。
