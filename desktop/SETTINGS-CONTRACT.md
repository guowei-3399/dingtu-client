# 助手“我的”配置清单

## 访问状态
- 未登录、会话过期：主内容只显示内嵌登录/注册模块，不显示账号配置、偏好、帮助或重置入口。
- 会话读取中：只显示会话加载状态，不先显示登录表单。
- 已登录：显示账号、配置分组和维护入口；退出及会话失效立即移除配置。
- UI 隐藏不代替 API 鉴权。服务端写入仍需有效会话、CSRF、客户与成员权限检查。

## 配置归属与接入状态
| 分组 | 项目 | 归属 | 当前状态 |
|---|---|---|---|
| 账号 | 昵称、邮箱验证、密码修改、会话退出 | 账号服务 | 资料读取与退出已接入；资料和密码编辑待独立助手表单 |
| 套餐 | 等级、流量额度/用量/周期、到期日、流量和到期提醒阈值 | 服务端权益与计量 | 企业摘要已读取主出口/备用额度；流量用量与周期待资源 API；不可展示演示值为已购权益 |
| 设备 | 设备名、平台、版本、最近在线、授权设备/同时在线客户端上限、撤销授权 | 服务端设备服务 | 摘要契约已保留 `unknown` 状态；设备注册表未接入前不把 auth.session 当设备，限制须服务端执行 |
| 连接 | 启动、自动连接、入口优选、自动重连 | 本机偏好与原生内核 | 启动与自动连接只保存偏好；入口和重连待内核 |
| 网络保护 | 断线保护、DNS 策略、IPv6 与泄漏检测 | 原生内核及服务端策略 | 待接入，按平台能力显示；不可修改出口绑定 |
| 出口 | 独立 IP、专属备用池、切换阈值、粘性和回切规则 | 服务端 | 助手只读；不能自定义出口、共享其他账号 IP 或手动绕过绑定 |
| 本地订阅池 | 已授权订阅槽位、额度摘要、重置时间、冷却状态、切换记录 | 客户/企业成员设备本地安全存储 + 本地调度器 | 原始凭据不上传；服务端只接收脱敏状态和审计事件；成员之间不共享槽位 |
| 应用 | 默认应用、官方入口、安装检测、启动行为 | 本机 | 默认应用与官方入口已实现；安装检测和原生启动待接入 |
| 提醒 | 连接异常、备用接管、流量阈值、到期、通知权限 | 本机及服务端事件 | 本机异常提醒偏好已实现；其余待服务端事件和系统通知 |
| 外观 | 深浅主题 | 本机 | 已保存，手机默认暗色、桌面默认亮色 |
| 维护 | 版本、更新渠道、更新记录、日志级别、日志保留、脱敏导出 | 客户端/运维策略 | 本机脱敏诊断可导出；更新及日志策略待接入 |

未接入项以只读状态行展示，不提供无实际效果的可编辑开关。后续按平台能力逐项启用。

## 客户端只读契约

主站客户域提供 `GET /api/v1/assistant/overview`，按当前会话与企业成员 RLS 返回 `data_source: "real"`、订阅额度、设备摘要、出口绑定和可见连接身份。接口不返回公网 IP、原始凭据、Cookie 或运营端令牌；客户端没有写出口、改套餐或分配身份的接口。设备服务尚未部署时返回 `devices.status: "unknown"`，界面明确显示“待原生客户端接入”。外部 API 网站额度不属于本接口，后续以独立上游合同接入。
